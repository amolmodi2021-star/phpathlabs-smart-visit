

# Fix: Barcode Not Readable by Scanner

## Root Cause
The barcode is generated by `JsBarcode` onto a small canvas (`width: 1.5`, `height: 30px`, no margin), exported as PNG, then **stretched** to `42mm × 7mm` in the print HTML via inline `style="width:42mm;height:7mm"`. This causes:

1. **Bar-width distortion** — A 1.5px bar module stretched to ~42mm produces blurry, unevenly-rounded bars when the printer rasterizes the image. CODE128 scanners need crisp, high-contrast bar/space ratios.
2. **No quiet zone** — `margin: 0` removes the mandatory ~10× module quiet zone on each side. Most scanners refuse to decode without it.
3. **Low source resolution** — A ~30px-tall barcode upscaled to 7mm (~26px at 96dpi screen, but stretched on a 203/300dpi thermal printer) loses bar edge sharpness.
4. **Anti-aliasing on stretched PNG** — Browsers apply image smoothing when scaling PNGs, blurring the bar edges further.

Note: `font-family: 'Arial'` is irrelevant — `displayValue: false`, so no font is used for the barcode itself.

## Fix — `src/components/lims/SampleCollection.tsx` (lines 259-275)

1. **Generate barcode at high resolution natively sized for the label**:
   - Use `width: 2` (module width in px) and `height: 60` for crisper bars
   - Add `margin: 10` to create a proper quiet zone
2. **Render at native pixel size, not stretched**:
   - Remove `width:42mm;height:7mm` inline style on the `<img>`
   - Instead, use CSS `max-width: 42mm; height: 7mm; image-rendering: pixelated;` so bars stay crisp on the thermal printer
3. **Add `image-rendering: -webkit-optimize-contrast` / `pixelated`** to disable the browser's smoothing of the barcode PNG during print
4. **Increase canvas pixel density** by rendering at 2× then letting print scale down (sharper than stretch-up)

## Single file change
- `src/components/lims/SampleCollection.tsx` — lines 259-275: barcode generation params + image CSS

## Why this works
Thermal/laser scanners need ≥0.25mm minimum bar width, sharp edges, and a quiet zone of 10× the narrow bar. Generating at higher native resolution + adding margin + disabling smoothing produces a print-ready barcode that scanners decode reliably.
